# Playwright 端到端演示

这些是**模拟 API 的前端 E2E 演示**：Playwright 使用本机 Google Chrome 打开真实 Vue 页面，但拦截 Gateway 请求并返回可控的演示数据。因此它适合稳定展示认证和项目管理的交互，不会创建或修改任何真实后端数据。

- 登录表单校验；
- 登录后首页项目与任务统计；
- 首页进行中项目展示；
- 我的项目查询、新建与收藏；
- 我的任务新建与筛选。

运行环境需要 Node.js 18 或更高版本，并安装 Google Chrome。测试默认复用本机 Chrome，因此首次运行无需下载浏览器。

运行演示：

```bash
npm test
```

测试报告生成于 `playwright-report/`；失败时会保留截图和追踪文件，便于课堂或答辩演示定位。
